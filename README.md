# Lore Lens

ส่วนขยายของ SillyTavern สำหรับดูว่าเอนทรี World Info / lorebook ตัวไหนถูกใส่เข้า prompt, คีย์เวิร์ดไหนทำให้ติด และไปเจอคีย์นั้นที่ไหน ใช้เป็นข้อมูลปรับคีย์ของ lorebook ได้

ตัวนี้เขียนมาแทน WorldInfo Info โดยปรับให้ใช้บนมือถือได้ง่ายขึ้น และทำงานร่วมกับ Quick Dock ได้

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

ถ้าติดตั้ง **WorldInfo Info** ไว้ ให้ปิดหรือลบก่อน เพราะสองตัวนี้ทำหน้าที่เดียวกัน

ต้องใช้ SillyTavern รุ่นที่มี event `WORLDINFO_SCAN_DONE` (ทดสอบกับ 1.19.0) ถ้ารุ่นเก่าเกินไป จะมีคำเตือนขึ้นใน console

## ใช้ได้บนอุปกรณ์แบบไหนบ้าง

Lore Lens ทำงานในเบราว์เซอร์ทั้งหมด ไม่มีส่วนที่รันบนเซิร์ฟเวอร์ ไม่ว่าจะรัน SillyTavern ไว้ที่ไหนก็ใช้ได้เหมือนกัน

| วิธีเล่น | ใช้ได้ | หมายเหตุ |
|---|---|---|
| Android + Termux (SillyTavern รันบนมือถือเอง) | ✅ | เปิดผ่าน Chrome / Samsung Internet ที่ `http://127.0.0.1:8000` |
| PC ที่รัน SillyTavern เอง | ✅ | บนคอมแผงจะเป็นการ์ดที่มุมขวาล่าง |
| เปิด SillyTavern บน PC จากมือถือผ่าน Wi-Fi (`http://192.168.x.x:8000`) | ✅ | ดูเรื่องคลิปบอร์ดด้านล่าง |
| เว็บโฮสต์ / เซิร์ฟเวอร์ภายนอก (รวม iOS) | ✅ | ติดตั้งผ่าน URL ได้เลย ไม่ต้องแก้ไฟล์บนเซิร์ฟเวอร์ |

**Android + Termux**
- ต้องอัปเดต SillyTavern ก่อน ถ้าลงไว้นานแล้ว ปิดเซิร์ฟเวอร์ (Ctrl+C) แล้วสั่ง
  ```
  cd SillyTavern
  git pull
  bash start.sh
  ```
- การติดตั้งผ่าน URL ต้องมี git ใน Termux ถ้าลง SillyTavern ด้วย `git clone` ก็มีอยู่แล้ว ถ้ายังไม่มี ให้สั่ง `pkg install git`
- ประวัติของ Lore Lens เก็บในเบราว์เซอร์ ไม่ได้อยู่ในโฟลเดอร์ของ Termux ถ้าล้างข้อมูลเว็บไซต์หรือล้างแคชของ Chrome ประวัติจะหายไปด้วย ส่วนแชทและ lorebook ไม่ได้รับผลกระทบ

**PC ที่โฮสต์เอง**
- ถ้าเปิดทั้งจาก PC และจากมือถือ แต่ละเครื่อง (แต่ละเบราว์เซอร์) จะเก็บประวัติและรายงานของตัวเอง เครื่องที่กดเจนเป็นเครื่องที่เก็บผลสแกน การตั้งค่าหน้าตาปุ่มใช้ร่วมกันทุกเครื่อง เพราะเก็บไว้ในการตั้งค่าของ SillyTavern
- ถ้าเปิดผ่าน `http://192.168.x.x` เบราว์เซอร์บางตัวไม่อนุญาตให้คัดลอกลงคลิปบอร์ดบน http Lore Lens จะใช้วิธีสำรองเอง ถ้ายังคัดลอกไม่ได้ ให้ใช้ปุ่มดาวน์โหลด .md แทน ซึ่งใช้ได้ทุกกรณี
- ถ้าใช้โหมดหลายผู้ใช้ของ SillyTavern ติดตั้งให้เฉพาะตัวเองหรือให้ทุกคนก็ได้ การตั้งค่าแยกกันตามบัญชี

**เบราว์เซอร์:** Chrome, Edge, Samsung Internet และ Safari รุ่นปัจจุบันใช้ได้ Firefox ต้องเป็นรุ่น 125 ขึ้นไป คำเตือน ⚠ ว่าคีย์ไทยไปติดกลางคำถึงจะทำงาน ถ้ารุ่นเก่ากว่านั้น ส่วนอื่นยังใช้ได้ปกติ

**ไม่กินโควต้า API:** Lore Lens ไม่เรียก API ของโมเดลเลย การสแกนเป็นของ SillyTavern ที่ทำอยู่แล้วทุกครั้งที่เจน Lore Lens แค่อ่านผลที่ได้ ใช้กับ API key ฟรี (เช่น Google AI Studio) ได้โดยไม่เสียโควต้าเพิ่ม

## แต่ละแท็บแสดงอะไร

แตะปุ่มรูปหนังสือเพื่อเปิดแผง บนมือถือแผงจะขึ้นจากขอบล่างของจอ ลากแถบด้านบนลงเพื่อปิด ส่วนบนคอมจะเป็นการ์ดที่มุมขวาล่าง

**ที่ติด** คือเอนทรีที่เข้า prompt ในการสแกนครั้งนั้น
- 🔑 คีย์หลักที่ทำให้ติด และคีย์รองที่เจอ
- ที่ที่เจอคีย์: ข้อความ #ไหน (ของผู้ใช้หรือบอท), Author's Note, คำอธิบายตัวละคร หรือเนื้อหาของเอนทรีอื่น (recursion)
- แตะแถวเพื่อดูข้อความรอบคีย์ คีย์ทั้งหมด (ตัวที่ทำให้ติดจะเป็นสีเด่น) ตรรกะของคีย์รอง และเนื้อหาเอนทรี มีปุ่ม **เปิดใน lorebook** ที่พาไปยังเอนทรีนั้นในตัวแก้ไข
- 🟢 คีย์เวิร์ด · 🔵 constant · 📌 sticky · ⚡ ถูกสั่งให้ติด (vector / extension) · `R2` = ติดจาก recursion รอบที่ 2
- ⚠ บนคีย์ภาษาไทย แปลว่าเจอคีย์อยู่กลางคำอื่น เช่นคีย์ `ยา` ไปเจอใน `พยายาม` ภาษาไทยไม่เว้นวรรคระหว่างคำ ตัวเลือก "match whole words" จึงกันกรณีนี้ไม่ได้ Lore Lens ใช้ตัวตัดคำภาษาไทยของเบราว์เซอร์ตรวจแทน

**เกือบติด** คือเอนทรีที่คีย์หลักตรงกับข้อความ แต่ไม่ได้เข้า prompt พร้อมเหตุผล เช่น คีย์รองไม่ผ่าน, แพ้ใน inclusion group, งบ token เต็ม, ทอยความน่าจะเป็นไม่ผ่าน, ติด cooldown หรือ delay

**สถิติแชทนี้** รวมผลจากการสแกนทุกครั้งในแชทนี้
- เอนทรีไหนติดกี่ครั้ง ติดด้วยคีย์ไหนกี่ครั้ง และคีย์ไหนไม่เคยเป็นตัวที่ทำให้ติด
- เอนทรีที่เกือบติดแต่ไม่เคยติดจริง และเอนทรีที่ไม่เคยติดเลย
- ส่งออกเป็นรายงาน Markdown (คัดลอกหรือดาวน์โหลด .md) หรือเป็น JSON

ใช้ปุ่ม ‹ › บนหัวแผงเพื่อย้อนดูการสแกนครั้งก่อน ๆ

## รายงานรายข้อความ

ใช้เช็คว่าแต่ละคำตอบได้ lore ไปตามที่ตั้งใจไว้หรือไม่ เปิดรายงานได้ 3 ทาง:
- เมนู **…** ของคำตอบบอท → ปุ่มรูปหนังสือของ Lore Lens
- แท็บ "ที่ติด" → แถบ **คำตอบที่ได้: ข้อความ #n · ดูรายงาน**
- คำสั่ง `/lorelens report` (คำตอบล่าสุด) หรือ `/lorelens report 12`

ในรายงานมี:
- **ข้อความก่อนหน้า, คำตอบ และ Chain of thought** คำที่เป็นคีย์ของเอนทรีที่ติดจะถูกไฮไลต์ไว้
- **เอนทรีที่ติด** บอกคีย์ที่ทำให้ติด, เจอคีย์ที่ไหน, ข้อความรอบคีย์, ตำแหน่งที่แทรกใน prompt (ก่อน Char Defs, @D4 ฯลฯ) และ **เนื้อหาที่ใส่ใน prompt จริง** (แทน macro แล้ว)
- **💬 / 🧠** บอกว่าคำตอบหรือ CoT มีคีย์ของเอนทรีนั้น ใช้ดูว่าโมเดลหยิบ lore ไปใช้หรือเปล่า ตัวนี้ตรวจจากคีย์อย่างเดียว ไม่ได้อ่านความหมาย
- **เกือบติด / ถูกตัด** พร้อมเหตุผล ถ้าคำตอบพูดถึงเอนทรีที่ไม่ได้เข้า prompt จะขึ้น ⚠
- **คำตอบพูดถึง แต่ไม่ได้ถูกสแกนเจอ** คือเอนทรีที่โมเดลพูดถึงเองโดยไม่มี lore ของเอนทรีนั้นใน prompt อาจเป็นจุดที่โมเดลแต่งรายละเอียดขึ้นมาเอง ส่วนนี้จะขึ้นหลังจากสแกนไปแล้วอย่างน้อยหนึ่งครั้งในรอบที่เปิด SillyTavern อยู่
- ถ้าข้อความเดียวกันมีทั้งการเจนและการกด continue รายงานจะแยกผลสแกนเป็นรายครั้ง ส่วนแต่ละ swipe มีรายงานของตัวเอง

ส่งออกเป็น Markdown ได้ (คัดลอก หรือดาวน์โหลด .md) และที่แท็บสถิติมีปุ่ม **รายงานทุกข้อความ** สำหรับรวมรายงานของทุกคำตอบในแชทเป็นไฟล์เดียว

รายงานมีเฉพาะคำตอบที่เจนหลังติดตั้ง v1.2 บนเบราว์เซอร์เครื่องนี้ และยังอยู่ในจำนวนที่เก็บย้อนหลังไว้

## ปรับหน้าตาปุ่ม

ตั้งค่าได้ที่ Extensions → Lore Lens → หน้าตาปุ่ม ปุ่มจริงจะเปลี่ยนตามทันทีที่ปรับ

รูปแบบปุ่มมี 5 แบบ:
- **คลาสสิก** ไอคอน มีตัวเลขจำนวนเอนทรีที่ติดอยู่มุมขวาล่าง
- **มินิมอล** มีแค่ตัวเลข ก่อนการสแกนครั้งแรกจะแสดงไอคอนแทน
- **แคปซูล** ไอคอนกับตัวเลขอยู่เรียงกัน
- **แถบขอบจอ** แปะชิดขอบจอเหมือนที่คั่นหนังสือ กินที่จอน้อย ลากไปขอบไหนก็หันตามขอบนั้น
- **วงแหวน** ตัวเลขอยู่ตรงกลาง วงแหวนรอบนอกเทียบจำนวนเอนทรีที่ติดครั้งนี้กับครั้งที่ติดมากที่สุดในแชทนี้ ถ้าวงเกือบเต็มแปลว่าเทิร์นนี้ดึง lore มาเยอะ

ปรับเพิ่มได้อีก:
- ขนาดปุ่ม และขนาดไอคอน/ตัวเลข
- สีไอคอน, สีพื้น, สีขอบ และสีตัวเลข/สีเน้น เลือกได้จากสีของธีม SillyTavern หรือกำหนดเอง (ชุดตัวเลือกเดียวกับ Quick Dock) สีเน้นจะใช้กับแผงด้วย
- ความทึบของพื้นปุ่ม และความทึบของทั้งปุ่มตอนไม่ได้ใช้ ปุ่มจะกลับมาชัด 100% เมื่อแตะ, เมื่อชี้ด้วยเมาส์ และเมื่อมีการเตือน
- ไอคอน เลือกจาก Font Awesome หรือใช้อีโมจิก็ได้
- เงาใต้ปุ่ม, เบลอพื้นหลังใต้ปุ่ม และซ่อนตัวเลขเมื่อไม่มีเอนทรีติด

## ใช้กับ Quick Dock

- เก็บปุ่มเข้า dock: Quick Dock → ปุ่มลอย แล้วกดค้างที่ปุ่มหนังสือ ตัวเลขบนปุ่มคือจำนวนเอนทรีที่ติดล่าสุด
- แผงของ Lore Lens อยู่ติดขอบจอเสมอ ไม่ได้ลอยตามตำแหน่งปุ่ม จึงไม่เด้งไปผิดที่ตอน Quick Dock หุบ
- ถ้างบ token ของ World Info เต็ม ปุ่มจะขึ้นสถานะ attention และปุ่มหลักของ Quick Dock จะมีจุดแดง จุดจะหายเมื่อเปิดแผงดู
- ทำเป็นช็อตคัทได้ด้วยคำสั่ง `/lorelens` หรือ `/lorelens stats`

## ข้อมูลเก็บไว้ที่ไหน

- ไม่เขียนอะไรลงไฟล์แชทหรือ chat metadata และไม่ดัดแปลง console
- ประวัติเก็บใน IndexedDB ของเบราว์เซอร์ที่ใช้อยู่ เก็บสูงสุด 30 ครั้งต่อแชท (ปรับได้) และสูงสุด 40 แชท ถ้าเปิดจากอีกเครื่องจะไม่เห็นประวัติของเครื่องนี้
- การเจนแบบ dry run (เช่นการนับ token) จะไม่ถูกนับ ส่วนการเจนแบบ quiet ของ extension อื่น เช่น summary หรือ tracker จะไม่ถูกนับตามค่าเริ่มต้น

## Lore Lens รู้ได้อย่างไรว่าคีย์ไหนทำให้ติด

SillyTavern บอกแค่ว่าเอนทรีไหนติดและติดในรอบสแกนที่เท่าไร ไม่ได้บอกว่าคีย์ไหนตรง Lore Lens จึงค้นหาคีย์อีกครั้งด้วยกติกาเดียวกับเอนจิน ได้แก่ scan depth ของแต่ละเอนทรี, case sensitive, whole words, คีย์แบบ `/regex/`, macro อย่าง `{{char}}`, prompt regex, การใส่ชื่อผู้พูด, ข้อความที่ถูกซ่อน, การ swipe และ recursion

ผลจึงตรงกับเอนจินเกือบทุกกรณี ยกเว้นกรณีที่คีย์อยู่ในไฟล์แนบหรือในข้อความที่ extension อื่นแทรกเข้ามาเอง แบบนี้จะขึ้นว่า ❔ หาตำแหน่งคีย์ไม่เจอ
